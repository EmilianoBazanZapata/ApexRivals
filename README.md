# 🏎️ Apex Rivals — `archive/blocking`

> **Archived branch.** Early prototype (MVP) of Apex Rivals, kept as a record of how the project started.

This was the working branch while the first playable prototype was blocked out, between **1 and 5 September 2026**. Its 19 commits are kept separate on purpose, so every early step can be reviewed on its own. It is no longer developed: the finished game is on [`main`](../../tree/main).

## What the prototype built

| Area | Commits |
| --- | --- |
| Project | Initial demo structure, architecture and test assemblies |
| Driving | Arcade driving vertical slice |
| Race | Checkpoint and lap progression |
| AI | Waypoint-based racing opponents and race-based difficulty |
| Progression | Reward and garage upgrade loop |
| Save | Minimum player profile persistence |
| Vehicle selection | Vehicle catalog, race setup and locked initial choice |
| Race session | Race lifecycle and rewards |
| UI and settings | Code-only presenters and preferences, then the functional demo screens |

The greyboxing and blocking of the first circuit happened here, which gives the branch its name.
