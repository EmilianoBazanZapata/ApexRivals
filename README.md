# 🏎️ Apex Rivals — `release/1.0`

> Version **1.0** of Apex Rivals with its **complete development history**.

This branch holds exactly the same game as [`main`](../../tree/main), but keeps every step that led to it: the playable demo and the pull requests that followed it, from **PR 73 to PR 101** (September – November 2026). `main` presents the same version as a single, clean commit.

Use this branch to review how each system was built, integrated and fixed. For the game itself (features, controls, architecture, how to run it) see the [main README](../../tree/main#readme).

## What version 1.0 contains

- Career mode with nine objectives and the **Apex Rivals Final**.
- Four circuits: Apex, Dunes, Crossover and **Riverdale** (final only), three laps each.
- Three AI rivals per race with racecraft, drifting and recovery.
- Garage with 8 cars to buy and Engine / Handling upgrades.
- Drift-charged nitro, dynamic weather, dynamic driving line and Cinemachine pre-race intro.
- Synthesised engine audio, soundtrack playlist, URP post processing and graphics settings.
- Modular monolith: one assembly per module.
- 799 Edit Mode and 125 Play Mode tests.
